# SMPR 与《量子比特路由路线初步》的方法差异

## 一句话结论

《量子比特路由路线初步》设计的是一个更复杂的**单路由器内部决策机制**：
用关键路径加权势函数、1--3 步自适应 Beam Search、局部门抵消估计和带回滚
repair 改进每一步 SWAP。SMPR 解决的是不同层级的问题：它构造多个真实完整
路由候选，迁移 LightSABRE 发现的优质初始布局，并始终保留 LightSABRE
候选，以统一质量键和线路审计完成**安全组合选择**。

两者不是互斥替代关系。前者最适合成为 SMPR 中新的候选生成分支；SMPR 的
安全选择层仍负责阻止该新分支在单个实例上造成质量退化。

## 共同基础

两者都继承 SABRE/LightSABRE 的基本框架：

1. 以逻辑门 DAG、动态前沿和逻辑--物理映射表示路由状态；
2. 使用硬件最短路距离评价尚未满足的双比特门；
3. 从前沿或未来门端点及其最短路径附近生成候选 SWAP；
4. 通过多初始布局、正反遍历或更深搜索降低单一步骤贪心的偶然性；
5. 使用停滞检测或释放机制避免局部循环。

因此，表面公式有重叠并不意味着两者是同一算法。真正的分界在于“候选如何
评价”和“最终质量由什么机制保证”。

## 核心差异

| 维度 | 《路线初步》 | SMPR |
|---|---|---|
| 研究对象 | 一个强化的单路由策略 | 多个完整路由器/布局候选的安全组合 |
| 单步评价 | 加权势函数、解锁收益、局部门成本、深度增量和振荡惩罚的线性组合 | 先用冻结启发式筛出前 \(k\) 个动作，再把每个动作后的剩余线路完整 rollout 到终点 |
| 搜索深度 | 根据评分差距和停滞程度，在 1、2、3 步 Beam Search 间切换 | 通常只比较前 \(k=2\) 个首动作，但每个动作都评估完整剩余线路；特殊冻结子类取 \(k=4\) |
| 初始布局 | 全局、早期、晚期交互图、多次局部改进和正反虚拟路由 | 20-seed LightSABRE 布局、独立布局池，以及 LightSABRE 并列最优布局的一换位邻域 |
| 布局迁移 | 布局池由该路由器自身生成 | 一个分支发现布局，另一个完整路由策略从原始线路冷启动重新解释该布局 |
| 目标函数 | 文档中仍未决定 SWAP 与深度的平衡；多项权重与阈值待定 | 冻结为 \((\mathrm{SWAP},D_{\mathrm w})\) 字典序，之后才用来源、种子和映射确定性破平 |
| 退化保护 | 未显式保留强基线，Beam/repair 可能改善也可能退化 | LightSABRE 最优候选始终在组合中，因此逐实例 SWAP 不劣；等 SWAP 时加权深度也不劣 |
| 循环处理 | 状态哈希、无进展计数、回滚无效后缀和最短路强制推进 | rollout 只在剩余 SWAP 严格改善时替换基线首动作；底层策略仍有停滞释放，组合层保留基线 |
| 指标可信度 | 局部有效门成本依赖门分解和局部优化器，尚无输出级验证说明 | 每个选中线路执行语义、拓扑和指标三重审计，并保存 QASM/QPY、映射与哈希 |
| 参数状态 | \(\theta,W,\gamma,\alpha,K_E,B,\eta,\lambda,\varepsilon\) 等大量参数待定 | V5/V6 参数已冻结，V6 为预注册盲测；V7 在观察结果前冻结协议 |
| 证据成熟度 | 7 页方案草稿，无实现结果、消融、盲测或统计区间 | V5/V6 完整复现，V6 120 例确认性证据；V7 10 条公共线路、heavy-hex 和同机质量--时间验证 |

## 为什么完整 rollout 与 1--3 步 Beam 不等价

Beam Search 的累计代价仍是代理函数。即使展开三步，它也可能偏好短期势函数
更好的路径，却把代价转移到更远处。SMPR 的完整 rollout 对候选首动作执行到
线路结束，直接以剩余 SWAP 比较，因此评价跨度更长；代价是计算量更大。

反过来，《路线初步》的 Beam Search 能在单次决策中保留多条近邻轨迹，并把
深度、局部门抵消和关键路径直接纳入搜索。若这些代理经严格冻结和盲测验证，
它可能比 SMPR 当前的独立展开策略更高效，也可能在部分实例上生成新的互补
候选。现有文件尚不能证明这一点。

## 最合理的合并方式

不要直接用该路线替换 SMPR。更稳妥的实验设计是：

1. 将其实现为新的 `adaptive_beam_repair` 候选分支；
2. 在只含开发数据的集合上确定全部权重、阈值和 Beam 宽度；
3. 冻结代码、参数、门分解、局部优化器和计时口径；
4. 保留 LightSABRE 与现有 SMPR 分支，在统一真实线路指标下选择；
5. 用新的未见数据做消融：单独新分支、原 SMPR、SMPR 加新分支；
6. 只有新分支在独立盲测中稳定贡献新增胜例，才把它写入下一版正式方法。

这样既能利用该草案的搜索创新，又不会丢失 SMPR 已经建立的逐实例安全下界和
审计链。
