## 2. 主要实证结论

V6 是确认性证据。120 个预注册盲测实例上，20-seed LightSABRE 与 SMPR
总 SWAP 分别为 3176 和 3051，减少 125 个（3.9358%），逐实例胜/平/负为
50/70/0。实例 bootstrap 95% 区间为 `[-0.024346,-0.013634]`，60 个
因子单元 cluster bootstrap 区间为 `[-0.024392,-0.013594]`。

V7 是前瞻冻结的外部验证。10 条 QASMBench 公共线路覆盖 11--23 个逻辑
比特和 19/57 比特 heavy-hex。三次同机重复形成 120 条配对观测。相对
时间匹配 LightSABRE，SMPR 在 `0.25T/0.5T/1T/2T` 四档预算下分别减少
11.05%/8.84%/7.30%/5.17% 的总 SWAP。四个按公共线路聚类的 95% 区间
均轻微包含零，因此只能报告正向汇总趋势，不能声称 95% 水平的普遍显著优势。

## 3. 推荐使用顺序

1. 解压公开核心到新目录，不要与历史项目目录混合。
2. 按公开核心 `README.md` 创建 Python 3.10 或 3.11 虚拟环境并安装冻结依赖。
3. 运行 `python -m smpr_router doctor` 和全部单元测试。
4. 运行五例 V5 冒烟测试。
5. 如需复现 V5/V6，执行公开核心对应的冻结脚本。
6. 如需复现 V7，在新的公开核心副本中依次运行 `prepare_v7.py`、
   `freeze_v7.py` 和 `run_v7.ps1`。冻结后不得更改代码、数据或参数。
7. 用两个证据 ZIP 和本目录 `SHA256SUMS.txt` 检查复现输出。

## 4. 结论边界

- V6 支持冻结合成分布上的显著总体改善与逐实例零 SWAP 退化。
- V7 支持公共线路和 heavy-hex 上的正向质量--时间趋势，但 cluster 区间跨零。
- 路由组合的安全下界来自候选集中显式保留 LightSABRE，不代表全局最优。
- V7 保留 CX 交互和依赖结构，一比特门被规范化为路由占位；它不是原始
  非 Clifford 线路的完整幺正等价证明。
- 持久分片的加速比较针对同一 SMPR 实现的执行方式，不代表 SMPR 总是快于
  单独 LightSABRE。
