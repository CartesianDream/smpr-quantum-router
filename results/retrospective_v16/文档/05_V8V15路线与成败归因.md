# 五、V8–V15 研究路线与成败归因

> 2026-08-07。记录 V8 至 V15 的完整研究路线：每一版本的方法、结果、
> 成败判定与归因，以及可迁移的关键教训。V16 的每一项改进均可在此追溯其
> 成功前提与失败规避。

## 5.1 路线总览

| 版本 | 主题 | 结果 | 判定 |
|------|------|------|------|
| V7 | 单策略结构势函数 + 预注册协议 | 自研基线 1855/3430（合成）；公共协议建立 | 基线/协议 |
| V8a | 增强布局池 | 较 V7 减少 8.25% SWAP | 成功 |
| V8b | 搜索改进 | 无增益 | 失败 |
| V10 | 六种势函数形状 | 仅超 V8a 0.41% | 失败（边际极小） |
| V10 | 决定性根因实验 | 路由超 LightSABRE 61，自研布局差 34 | 根因定位 |
| z3 | 精确最优性 | 7 个 n≤6 case 证明理论最优 | 证据 |
| V13 | 多种子前向束搜索 | 全量 1669（差 V10 的 1667 约 2），时间 2× | 失败 |

## 5.2 逐版本记录

### V7（协议地基）
建立预注册、哈希冻结、同机质量—时间对比的评估协议，并在公共 QASMBench
10 条 heavy-hex 电路上完成外部验证。路由为单策略结构势函数，合成基准
1855/3430。**意义**：奠定可信评估框架，后续所有版本的结论可复核。

### V8：布局池增强成功，搜索改进失败
- **V8a 成功**：增强布局池（LS + 交叉布局）较 V7 减少 8.25% SWAP。
  布局多样性直接转化为路由质量。
- **V8b 失败**：路由搜索模式的改进无增益。**归因**：路由搜索空间在原
  参数下已接近局部最优，单点改进无法突破。

### V10：形状探索边际化，根因定位
- **六种势函数形状仅超 V8a 0.41%**。**归因**：势函数形状的调整属于
  "同族微调"，收益递减。
- **决定性根因实验**：同一批 LightSABRE 布局下，双搜索路由 vs LightSABRE
  路由 = 1633 vs 1694（路由强 61）；但自研矩阵布局 vs LightSABRE 布局 =
  差 34。**结论**：路由已是强项，短板在布局源。这一判断直接决定了 V13
  回退到 V5 布局库的路线选择。

### z3：精确最优性证明
对 7 个 n≤6 case 以 SMT 求解严格证明 V10+ 已达理论最优（UNSAT 下界），
证实小 case 的零浪费。**意义**：为"路由已接近最优"提供形式化证据。

### V13：束搜索失败，双搜索路由成功
- **多种子前向束搜索失败**：全量 1669，仅差 V10 的 1667 约 2，时间翻倍。
  **归因**：束搜索在已充分优化的路由上边际为零，且计算成本线性上升。
- **正式方案成功（V5+ 精进）**：回到 V5 布局库（依据 V10 根因结论），
  路由改为双通道组合（ordered_rollout + terminal_two_step），
  B1 1615 / B2 3021（相对 V5 −1.6% / −1.0%）。**成功前提**：布局源用
  LightSABRE（强项），路由用组合精进（强项），各取所长。

### V14：评估驱动策略发现（方法转折）
将策略表示为势函数 × 参数 × 候选集 × 搜索模式网格，208 个策略点在
40 个开发 case 上真实评估，贪心集合覆盖选出 12 个互补通道，per-case min
组合。B1 1574 / B2 2930（相对 V13 −2.5% / −3.0%）。
**关键发现**：单最佳通道远逊于组合（组合增益来自通道互补性，portfolio
效应）。**教训**：通道集必须包含 V13 双通道——否则历史冠军被挤出，个别
case 比 V13 差（已实测并修复）。**成功前提**：真实成本评估（非代理）、
贪心覆盖保留互补性。

### V15：真实成本布局搜索 + 公共桥梁
- **布局搜索成功**：此前所有布局搜索失败均栽于失真代理与评估口径不一致。
  V15 将布局适应度与部署目标（多通道真实路由成本）严格对齐，B1 −7 /
  B2 −23，058 复现 22 < 24。**成功前提**：评估口径与部署一致。
- **公共桥梁成功**：12 通道在 V7 的公共 heavy-hex 电路上同布局 −7.8%、
  布局池 −18.7%，逐 case 0 回归。**意义**：合成基准的改进泛化到公共基准，
  论文叙事闭环。

## 5.3 成功与失败的归因总结

| 因素 | 成功的版本 | 失败的版本 |
|------|-----------|-----------|
| 布局源 | 用 LightSABRE 布局库（V13/V15） | 自研布局（V10 差 34） |
| 评估口径 | 真实成本、与部署对齐（V14/V15） | 失真代理、贪心口径（早期布局搜索） |
| 搜索空间 | 系统性网格 + 组合（V14 策略发现） | 单点/束搜索（V8b/V13 FB，边际为零） |
| 通道集完整性 | 保留历史冠军（V14 教训） | 挤出冠军（V14 初版，已修复） |
| 势函数族 | 跳出同族（V16 新势/新候选集） | 同族微调（V10 形状 0.41%） |

## 5.4 关键教训（可迁移）

1. **布局源决定下限**：路由再强，自研布局差则全盘输（V10 vs V5 根因）。
   复用强布局库 + 精进路由是正确组合。
2. **评估口径决定搜索成败**：失真代理导致布局搜索反复失败；真实成本对齐
   后立刻成功（V15）。任何自动发现必须以部署口径为准。
3. **组合优于单点**：路由搜索（FB/束搜索/门重排/反馈重布局）全阴性，
   说明"再优化单个策略"到顶；策略发现 + 通道组合才是出路（V14）。
4. **保留历史冠军**：通道集的构造必须包含已被验证的通道，否则组合
   per-case min 可能倒退（V14 实测教训）。
5. **突破需换族而非换参**：参数偏置（V14 第三轮）零增益，换势函数形状
   与候选集（V16）才有增益——"饱和"往往是网格的饱和，不是空间的饱和。
