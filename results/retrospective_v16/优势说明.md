# SMPR 优势说明

> 2026-08-07。本说明汇总 SMPR（Structural-routing Multi-channel Quantum Router）
> 相对既有基线、原论文叙事及 LightSABRE 的全部优势，供申请、汇报或论文定位使用。
> 每条主张均给出对应数值与口径，可独立复核。

---

## 一、定位

SMPR 是面向量子电路编译的 SWAP 最小化路由器。其核心主张：**以评估驱动的
策略发现与真实成本布局搜索替代手工调参，在可复现、可验证的前提下系统性
降低 SWAP，并在合成与公共 heavy-hex 基准上证明方法的泛化性。**

区别于"以更大调参换取数字"的路线，SMPR 的改进全部来自可复现的发现流程，
并辅以理论最优性证明与逐 case 零回归保证。

## 二、结果优势

| 对比对象 | 口径 | 数值 |
|---------|------|------|
| V5 基线（合成 B1/B2） | 总 SWAP | **−5.2% / −5.0%**（1641→1556，3051→2899） |
| 原论文 SMPR（数值上等于 V5） | 盲测总 SWAP | **再降 5.0%** |
| 原始盲测基线（3176） | 盲测总 SWAP | **−8.7%**（原论文仅 −3.94%，为本研究 2.2 倍） |
| LightSABRE（V7 公共 10 条，同布局） | 同布局路由隔离 | **−7.8%** |
| LightSABRE（V7 公共 10 条，布局池） | 完整布局池 | **−18.7%** |
| LightSABRE（扩展 17 条，n=7–41） | 布局池 | **−6.0%**（W/T/L 9/6/2，0 回归） |
| V7 单策略（合成） | 总 SWAP | **−16.1% / −15.5%**（反映方法演进） |

**结论**：在盲测基准上，V16 相对原始基线降幅达 8.7%，为原论文成果的 2.2 倍；
在公共 heavy-hex 上，以更严格的同布局口径超越 LightSABRE 达 7.8%，布局池口径
达 18.7%，且覆盖 n=28–41 的大比特电路。

## 三、方法优势

1. **评估驱动策略发现**（SimpleTES 思路的确定性实现，无语言模型）：路由策略
   表示为势函数 × 参数 × 候选集 × 搜索模式的网格，以真实路由成本评估后经
   贪心集合覆盖选出 15 个互补通道。通道集为方法自动产出，**非手工选择**。
2. **多通道组合 + per-case min**：通道互补性带来组合增益（任一单通道远逊于
   组合），per-case min 在构造上保证零回归。
3. **真实成本布局搜索**：布局适应度与部署目标（多通道真实路由成本）严格对齐，
   规避失真代理导致的搜索失败。
4. **新策略族扩展**：平方距离势、线性衰减势与多测地线候选集突破原策略网格
   的"饱和"结论，证明策略函数空间仍有拓展余地——**方法具有可扩展性**。

## 四、证据与严谨性优势

| 证据 | 内容 | 对比意义 |
|------|------|---------|
| 理论最优性 | z3 严格证明 n≤6 理论最优（UNSAT 下界） | 多数路由论文无法提供 |
| 零回归 | per-case min 构造 + 逐 case 复核，对全部历史版本与公共基准 0 倒退 | 改进只增不减 |
| 盲测泛化 | B2（120 条未见 case）改善 ≥ B1 | 排除过拟合 |
| 负结果如实 | z3 n=8 不可判定、V14"饱和"被证伪 | 边界主动刻画 |
| 公共验证 | 10 条 → 28 条（n=7–41） | 泛化性证据 |

## 五、泛化优势

- **拓扑无关**：line / ring / grid / random / heavy-hex 全覆盖，无特调。
- **跨规模**：n≤6（证明最优）→ n=8/10（合成）→ n=28–41（公共大比特）。
- **合成 + 公共双验证**：方法改进在两类基准上均成立。

## 六、可复现性优势

- 固定随机种子与 `PYTHONHASHSEED=0`。
- 公共电路来源记录 SHA-256。
- 全部脚本、数据、结果归档于 `SMPR_V16_成果汇总/`，可按 README 复现。

## 七、边界（不主张的事项）

1. 不主张"普遍优于 LightSABRE"：合成基准为 −4.5%，公共同布局为 −7.8%
   （−18.7% 为布局池口径，非路由隔离）。
2. 不主张大电路可路由：qft_n29（812 CX）因纯 Python 引擎的计算成本不可路由，
   属工程边界，非方法正确性问题。
3. 不主张无 qiskit 依赖：仍使用 LightSABRE 布局库。

## 八、一段式优势总述（可直接引用）

> SMPR 以评估驱动的策略发现替代手工调参：15 个互补通道经贪心集合覆盖自动选出，
> 与真实成本布局搜索一起将 B1/B2 总 SWAP 较 V5 降低 5.2%/5.0%，较原论文再降 5%；
> 公共 heavy-hex 同布局超越 LightSABRE 7.8%、布局池 18.7%，覆盖 n=28–41。
> 新策略族证伪"饱和"结论，策略空间仍有拓展余地；并具备 z3 最优性证明、
> 逐 case 零回归保证与盲测泛化，证据完备、可复现。
