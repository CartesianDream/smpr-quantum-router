# 复现说明

## 环境

- Python 3.10–3.12；
- Qiskit 2.4.2；
- qiskit-qasm3-import 0.6.0；
- `PYTHONHASHSEED=0`；
- BLAS、OpenMP、NumExpr 与 Rayon 线程数固定为 1；
- V5/V6 并行吞吐使用四个持久分片；
- V7 同机质量—时间比较强制单任务顺序执行。

`python -m smpr_router doctor` 会验证输入哈希、依赖版本、核心文件数和公开命名。

## V5/V6

V5 使用逐字段 `exact` 参考策略；V6 使用 `primary` 策略，排除未选中候选的
辅助深度和尝试次数，但严格比较选中分支、SWAP、深度以及三项审计。V6 的
这种策略边界来自既有独立隔离复算，不可再调整。

公开 V6 JSON 仅把一个不参与路由的原机器绝对路径替换为中性档案指针；实例、
种子、门序列、拓扑和冻结清单摘要均未改变。字节级原始输入保留在独立历史
档案中，公开配置固定的是这一可移植副本的 SHA-256。

恢复模式只恢复已经完整写入并通过元数据校验的分片。不完整分片目录会被
拒绝，防止把部分结果误当成功结果。恢复合并的墙钟时间不能作为性能数据。

## 输出完整性

每次运行写出逐实例 CSV、逐尝试 CSV、摘要 JSON、分片日志和 SHA-256 清单。
公开参考 CSV 删除不可移植的本机绝对 QASM/QPY 路径。完整原始文件只存在于
独立历史档案中，以维持原始哈希。

## 证据边界

冻结 V5/V6 的质量主张来自合成线路。V7 才承担公共线路、heavy-hex、超过
10 比特和同机质量—时间比较。V7 结果在冻结清单之后才可解释；失败结果也
必须保留并报告。
