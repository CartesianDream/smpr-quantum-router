# SMPR 算法说明

## 1. 输入与目标

输入为逻辑线路依赖 DAG、物理耦合图和候选初始映射。所有一比特门在其逻辑
线上保持原序；二比特门仅在两个逻辑比特当前映射到相邻物理点时执行。路由
动作是在物理边上插入 SWAP 并同步更新正、逆映射。

主质量指标是插入 SWAP 数，次指标是加权深度。普通一、二比特门持续时间为
1，抽象 SWAP 按三层二比特门计为 3。最终质量键为：

```text
(swap_count, weighted_depth, branch_priority, tie_key)
```

分支优先级仅在 SWAP 和深度完全相同时生效，LightSABRE 优先。

## 2. 结构势函数

冻结结构策略同时观察前沿集合与有序扩展集合。对候选映射 `pi`，势函数为：

```text
P(pi) =
  sum(distance(front_gate; pi))
  + sum(0.5^i * distance(extended_gate_i; pi)).
```

候选 SWAP 边来自前沿与扩展集合涉及的物理端点。评分还包含解锁奖励；只有
严格改进的完整策略展开才替换基线动作。确定性最短路、候选排序和缓存键都
使用显式排序，避免集合迭代顺序影响结果。

## 3. 完整策略展开

对每个候选首步，算法复制路由状态，执行该动作并运行同一冻结结构策略直至
线路完成。候选值为“当前一步 + 后续完成所需 SWAP”。只在候选总 SWAP 严格
少于基线完成轨迹时改变决策；因此局部展开不会仅凭短期势函数替换更优完整
轨迹。

## 4. 初始布局与跨布局迁移

独立展开从由交互矩阵产生的确定性布局池启动。跨布局分支首先运行多种子
LightSABRE，取最佳质量布局，随后评估该布局和最多四个代理分数最优的交换
邻居。代理分数按线路中二比特交互顺序指数衰减：

```text
proxy(pi) = sum(0.95^i * distance(interaction_i; pi)).
```

“布局由 LightSABRE 发现、路由由完整展开执行”的职责分离是 SMPR 的核心。

## 5. 安全选择

候选集包含本次 LightSABRE 最优结果，因此：

```text
quality(SMPR) <= quality(best LightSABRE candidate)
```

这里的 `<=` 是 `(SWAP, weighted_depth)` 字典序，并依赖以下运行条件：

- LightSABRE 分支成功完成；
- 候选审计通过；
- 选择器未过滤 LightSABRE；
- 比较的是同一次运行的候选集，而不是跨环境历史最优。

这一结构保证不等于“独立展开普遍优于 LightSABRE”，也不等于运行时间优势。
