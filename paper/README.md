# Paper

本目录提供可直接阅读的中文论文、独立实验报告和完整 XeLaTeX 源码包。

| 文件 | 内容 |
|---|---|
| `SMPR_Chinese_Paper.pdf` | 正式中文论文 |
| `SMPR_Experiment_Report.pdf` | 详细实验与可靠性报告 |
| `SMPR_LaTeX_Source.zip` | 两份文档、字体、参考文献、图表和证据表的完整源码 |

解压源码后使用 XeLaTeX。根文档为 `main.tex`；实验报告为
`experiment_report.tex`。源码包已经预渲染高开销图形，并包含 `latexmkrc` 和
本地字体，适合 Overleaf 或本地 TeX Live。

为便于 GitHub 直接浏览，解压后的同一份源码也保存在
`results/paper_source/`；该目录属于证据归档，不参与 Python 包安装。
